# Vue3 个人博客系统

一款基于 Vue3 + Vite + Element Plus 开发的现代化个人博客前端项目，集成工程化、性能优化、实时交互、权限控制等核心能力，适合前端开发者学习和二次开发。

## 🌟 核心功能

- **基础体验**：骨架屏、路由动画、全局Loading、回到顶部、暗黑模式、页面标题动态修改
- **表单增强**：Markdown编辑器、图片上传、表单验证、表单一键重置
- **数据展示**：表格封装、数据懒加载、数字滚动动画、空状态组件
- **交互动效**：按钮/卡片悬浮动效、文章逐行渐显、评论滑入动画、导航栏滚动响应
- **权限安全**：路由权限、按钮级权限、Token持久化、XSS防护、接口加密
- **工程化**：ESLint+Prettier规范、Mock数据、打包体积分析

## 🛠 技术栈

| 技术         | 版本 | 用途     |
| ------------ | ---- | -------- |
| Vue          | 3.4+ | 前端框架 |
| Vite         | 5.0+ | 构建工具 |
| Element Plus | 2.4+ | UI组件库 |
| Pinia        | 2.1+ | 状态管理 |
| Vue Router   | 4.2+ | 路由管理 |
| Axios        | 1.6+ | 网络请求 |
| WebSocket    | -    | 实时通信 |
